# 健壮性：重试 + 超时 + 错误分类

> 参考 Suna 的 `internal/runner`（completeWithRecovery）和 `internal/model/error.go`，
> 为模型调用加上重试、超时、错误分类，让 agent 更健壮。

---

## 一、为什么需要健壮性

模型调用是网络请求，**会失败**：
- 网络抖动、连接超时
- 限流（429）
- 服务器临时故障（5xx）

没有健壮性时，一次网络抖动就让整个对话崩溃。有了重试 + 超时 + 错误分类，agent 能自动恢复。

---

## 二、错误分类（errors.py）

参考 Suna 的 `error.go`，把异常统一分类成 `ModelError`。

### 错误类型（ModelErrorKind）
| 类型 | 含义 | 例子 |
|------|------|------|
| `http` | HTTP 错误 | 429 限流、500 服务器错误 |
| `network` | 网络错误 | 连接失败、超时 |
| `cancelled` | 用户取消 | KeyboardInterrupt |
| `unknown` | 未知错误 | 其他 |

### 分类规则（对应 Suna 的 modelErrorFromProvider）
```python
def classify_error(err):
    if isinstance(err, (APIConnectionError, APITimeoutError)):
        return ModelError(NETWORK, ...)   # 网络错误
    if isinstance(err, APIStatusError):
        return ModelError(HTTP, ..., status_code=err.status_code)  # HTTP 错误
    ...
```

## 三、重试逻辑（runner.py）

参考 Suna 的 `completeWithRecovery`。

### 核心：只重试"可重试"的错误
```python
def retryable(err):
    if err.kind == NETWORK: return True        # 网络抖动 → 重试
    if err.kind == HTTP:
        return err.status_code in {408, 429, 500, 502, 503, 504}  # 限流/5xx → 重试
    return False                                # 其他 → 不重试
```

**关键**：参数错误（400）、鉴权失败（401）、权限不足（403）**不重试**——重试也没用，反而浪费。

### 重试循环（对应 Suna 的 completeWithRecovery）
```python
MODEL_MAX_RETRIES = 3   # 最多重试 3 次
MODEL_RETRY_DELAY = 8   # 间隔 8 秒

def _one_call(self, messages, schemas, on_delta):
    for attempt in range(1, MODEL_MAX_RETRIES + 2):
        try:
            return self._do_call(messages, schemas, on_delta)
        except Exception as exc:
            err = classify_error(exc)
            if attempt >= MODEL_MAX_RETRIES + 1 or not retryable(err):
                raise
            time.sleep(MODEL_RETRY_DELAY)   # 等待后重试
```

## 四、超时保护

单次请求加超时，防止模型"话痨"或网络卡死：
```python
response = self.client.chat.completions.create(
    ...,
    timeout=MODEL_TIMEOUT,   # 60 秒
)
```

## 七、一句话总结

**健壮性 = 错误分类（知道错在哪）+ 重试（只重试可恢复的错误）+ 超时（防止卡死），
