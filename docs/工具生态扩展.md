# 工具生态扩展

> 参考 Suna 的 `internal/tools/builtin`，把内置工具从 3 个扩展到 9 个。

---

## 一、为什么扩展

升级前只有 3 个工具（read_file / list_dir / run_command），能力有限。
Suna 有 9 个内置工具。补齐后，agent 能读写文件、操作文件系统、搜索、发 HTTP 请求。

---

## 二、工具清单

| 工具 | 功能 | 参考 Suna |
|------|------|-----------|
| `read_file` | 读取文件 | ReadFile |
| `list_dir` | 列出目录 | ListDir |
| `run_command` | 执行命令 | Exec |
| `write_file` | 写文件（覆盖/新建/追加） | WriteFile |
| `edit_file` | 编辑文件（精确替换） | EditFile |
| `filesystem` | 文件系统操作（stat/mkdir/move/copy/remove） | FileSystem |
| `search` | 搜索文件内容 | Search |
| `read_image` | 读取图片 | ReadImage |
| `http` | HTTP 请求 | HTTP |

---

## 三、新增工具详解

### write_file（写文件）
```python
write_file(path, content, mode="overwrite", create_dirs=False)
# mode: overwrite 覆盖 / create_new 仅新建 / append 追加
```

### edit_file（编辑文件）
```python
edit_file(path, edits=[{"old_string": "...", "new_string": "..."}])
# 一次或多次精确替换，按顺序应用
```

### filesystem（文件系统操作）
```python
filesystem(action, path, destination="", recursive=False, ...)
# action: stat / mkdir / move / copy / remove
```

### search（搜索文件内容）
```python
search(query, path=".", max_results=50)
# 用正则搜索文件内容，返回匹配行
```

### read_image（读取图片）
```python
read_image(source)  # 本地路径或 http(s) URL
```

### http（HTTP 请求）
```python
http(url, method="GET", headers=None, body="", timeout=30)
```

---

## 四、Guard 适配

新增的只读工具（search / read_image）被 Guard 识别为只读，自动放行。
写操作（write_file / edit_file / filesystem）走模式策略（smart 模式 LLM 审查）。
