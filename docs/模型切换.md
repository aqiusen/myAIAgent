# 模型切换

> 在模型抽象（多提供商）基础上，加上运行时模型切换能力。

---

## 一、为什么需要模型切换

配置了多个模型后，需要能在对话中**随时切换**：
- 日常用便宜的模型（deepseek）
- 看图/复杂任务切换到多模态模型（gpt-4o）

---

## 二、配置多模型

在 `.env` 里配置（支持多行 JSON，注意不能有尾逗号/注释）：

```bash
MY_AGENT_MODELS=[{
  "ref": "vision",
  "model": "gpt-4o",
  "base_url": "https://api.openai.com/v1",
  "api_key": "sk-xxx"
}]
```

主模型（`MY_AGENT_MODEL`）永远是 `default`，额外模型用 `MY_AGENT_MODELS` 配置。

---

## 三、切换命令

在 TUI 对话里：

```
/model            # 查看当前模型和可用模型
/model vision     # 切换到 vision 模型
```

---

## 四、实现

### Agent.switch_model（对应 Suna 的 Router.Bind）
```python
def switch_model(self, ref):
    provider = self.registry.get_provider(ref)  # 从注册表取新 Provider
    self.runner.provider = provider             # 换 Runner 的 Provider
    # smart 模式的 LLM 审查器也跟着换
    self.guard.llm_reviewer = _default_llm_reviewer(provider, ...)
    self.model_ref = ref
```

### TUI /model 命令
```python
if text == "/model":
    self._show_models()      # 显示当前 + 可用
if text.startswith("/model "):
    self._switch_model(ref)  # 切换
```
